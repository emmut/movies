`NotoEmoji.ttf` is the upstream `NotoEmoji[wght].ttf` variable font (weights
300–700), downloaded on 2026-10-31. It uses monochrome outlines so browsers
without native emoji or color-font support can render emoji. It is served by
`next/font/local` and loaded on demand rather than preloaded on every page.

Inter stays the primary font. The emoji fallback is also included in Tailwind's
`font-sans` stack so controls that explicitly select sans-serif retain it.
